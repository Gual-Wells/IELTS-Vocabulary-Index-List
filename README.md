# Vocabulary Index 3.3.0

面向 iPhone Safari 主屏幕 PWA 的本地优先英语词汇与短语索引。

## 平台边界

- 唯一主要运行方式：Safari“添加到主屏幕”后的 standalone PWA；
- 单用户、单设备、本地 IndexedDB；
- 无账户、云同步或多设备合并；
- 其他人打开公开仓库时使用各自本地数据，不会影响本机。

## 3.3.0

3.3.0 在不改变 Schema 4、Seed revision 3 和词库业务内容的前提下，重构 iPhone 页面外壳、浮层、一级表项和标注状态：

- 状态栏安全区与固定紧凑导航；
- 滚动大标题与应用内首页位置恢复；
- PIN、标注审阅和首页标注警告均改为不参与文档流的覆盖层；
- 搜索、表单、确认和操作窗口按任务类型采用有边距的小型几何；
- 所有输入窗口默认不聚焦，不自动唤起键盘；
- 一级表项回归紧凑横向结构，并统一预留右侧关联附着轨道；
- 普通词汇与繁体释义共同横向滑动，不省略、不换行；
- 长短语采用两行压缩，极限短语使用约 1.5 倍高度的双区结构；
- Oxford 与 ChatGPT 合并为一个查询入口，通过双图标锚定菜单选择；
- 被 AI 标注的条目使用红色边缘渐变，点按直接进入标注处理；
- 首页提供不可关闭的黄色标注警告覆盖条及全局一键撤销；
- 当前词表标注审阅支持一键撤销当前词表全部标注；
- Seed 重置先自动发起完整备份下载，再显示小型确认窗口；
- 统一重绘主要图标和二级关联跳转图标；
- 保留长列表分块、关系索引、局部事务、滚动限流和 SVG 模板缓存。

## 本地运行

必须通过 HTTP(S) 打开：

```bash
python3 -m http.server 8000
```

在 iPhone Safari 访问部署地址，再通过分享菜单添加到主屏幕。
