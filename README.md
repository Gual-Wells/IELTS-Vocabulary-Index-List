# Vocabulary Index 3.4.0

面向 iPhone Safari“添加到主屏幕”场景的本地优先英语词汇与短语索引。

## 平台边界

- 主要运行方式：iPhone standalone PWA；
- 单用户、单设备、本地 IndexedDB；
- 无账户、云同步或远程业务数据库；
- 同一公开部署的不同访问者使用各自独立的浏览器数据。

## 3.4.0 核心变化

3.4.0 重构了四类系统总表的投影语义，并完成搜索、关系跳转、AI 异步一致性与移动端真机 UI 的一轮收口。

### 系统总表是投影视图

- 独立域词汇总表、独立域短语总表、全局词汇总表和全局短语总表都不拥有独立 Entry 或个人状态；
- PIN、AI 标注、学习日期、释义和关系始终属于具体 Entry；
- 同一 Entry 因多个普通表 Membership 被汇总时只显示一次；
- 跨独立域同形词／短语不再选取一个代表 Entry，而是在全局总表中分别显示；
- 跨域同形行只在排序、唯一计数和序号层面形成词形组；冲突行右上角显示来源独立域；
- 全局卡片与标题仍按唯一规范文本计数，实际渲染行数可更大。

### 交互与正确性

- 关系跳转改为唯一域内、唯一域外、多目标三态；多目标使用锚定扁平列表选择；
- 搜索改为先确定范围、再评分排序、最后截断，避免词表内结果被全局结果挤出；
- 当前字母温和跟随滚动，真实字母标题可吸附在动态顶部下方；点击吸附标题可稳定收起当前字母组；
- AI 过期结果不再清除有效旧标注，当前请求支持真正 Abort；一次核查只形成一条撤销历史；
- 导入计划绑定基准 Revision，确认期间数据变化时强制重新预检；
- 歧义 VIX 裸键不再猜测，脏归属被跳过并在预检中报告；
- 学习日期统一为具体 Entry 状态，旧 Schema 4 全局日期按旧代表规则保守迁移。

### 真机 UI

- 顶栏标题采用物理居中布局；顶部工具图标框内居中；
- 删除首页左侧装饰竖线；
- 移除全局区域渐变、系统卡片渐变与廉价阴影，建立纯色平面基线；
- 无序号模式释放左侧空间；日期为空时释放日期槽；
- 短语两行布局在可见块物化后进行真实溢出检查，必要时升级为极限布局；
- 横滑状态不跨 Entry、视图或重新物化周期持久化。
