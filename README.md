# Vocabulary Index 3.0.4

面向 iPhone Safari / 主屏幕 PWA 的本地优先英语词汇与短语索引。Windows Chrome 主要用于辅助管理。

## 日常路径

```text
进入列表 → 浏览或定位英文 → 点按复制 → 外部词典查询 → 返回原位置
```

## 3.0.4 交互原则

- 全局固定显示“全局总表、全局短语表”；每个词域固定显示“总词表、短语”，普通词表排在其后。
- 普通词表、词域总词表和全局总表只显示普通词汇；短语表和全局短语表只显示短语。
- 词汇行展开相关短语；短语行展开组成词汇。子项文字始终负责复制，跳转使用独立控件。
- 短语组成词跳到对应词域中优先级最高的普通词表，不跳到词域总词表。
- 搜索、关系、上次位置和 PIN 共用统一跳转反馈：已可见目标只高亮，长距离目标定位到有效视口上部约 38%。
- 上次位置准星永久位于导航栏首位；尚无位置时保持占位但禁用。
- PIN、关系、跳转、准星和更多均使用统一 SVG 图标与独立触控区域。
- 词性保留在数据层，但从日常浏览和搜索界面隐藏。
- 开启繁体释义后，释义在一级表项的英文后方单行显示，不增加行高。
- 高频关系与搜索读取使用内存索引，不复制整库，不进行按键级全量重算。

## 数据与功能

- Domain / Collection / Entry / Membership / PhraseToken；
- 词域内唯一，跨词域允许同形内容；
- 全局总表、全局短语表与词域总词表均为运行时派生投影；
- 词汇与短语双向关系；
- 可选繁体释义；
- TXT / Markdown / CSV / JSON 导入；
- 完整 JSON 备份与 2.4.1 → 3.0 迁移；
- 撤销、重做、PIN、标注和各列表独立位置；
- Groq 动态模型目录、AI 新增与分批核查；
- 用户确认式 PWA 更新和版本化离线应用壳。

## 部署

ZIP 根目录就是仓库根目录。整体替换仓库项目文件时保留 `.git`，不要与旧覆盖分支合并。

部署前先导出完整 JSON；部署后完全关闭旧 Safari / 主屏幕实例，再重新打开并按 `tests/MANUAL_CHECKLIST.md` 验收。
