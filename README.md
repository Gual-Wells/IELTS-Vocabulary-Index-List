# Vocabulary Index 3.5.0

面向 iPhone Safari“添加到主屏幕”场景的本地优先英语词汇与短语索引。

## 版本定位

3.5.0 保留 3.4.0 已完成的数据模型，重做其在真实 iPhone 上失控的页面运行时、导航和一级表项结构。

核心原则：

- 系统总表仍是具体 Entry 的特殊投影视图，不拥有独立内容或个人状态；
- 普通词汇继续由同域最高优先级普通词表唯一显示，短语仍按全部 Membership 显示；
- 普通词表拆分为词汇视图与短语视图，不再在同一页面同时渲染两套导航；
- 页面稳定性优先于动效，不对滚动、高度、sticky 位置或关系展开使用平滑动画。

## 3.5.0 主要变化

### 页面与导航

- 普通词表改为独立的“词汇视图／短语视图”，两者分别保存模式、位置和展开状态；
- 恢复固定底部五项工具栏：上次位置、回到顶部、字母／日期排序、词／短语切换、搜索；
- 系统总表的词／短语切换按钮禁用；
- 建立应用内部页面快照与返回栈，跨词表跳转后返回来源页面及其状态；
- 首页进入时位于顶部且全部字母收起；搜索或关系跳转只展开目标组；
- 同页面目标跳转不再依赖 URL 是否发生变化；
- 字母栏只包含字母，使用无动画 nearest 跟随，并正确处理 A 与 # 端点；
- 真实字母小标题自身 sticky，不再复制半透明毛玻璃标题。

### 一级表项

- 删除外挂序号框，序号改为正文前置文本；
- 删除右侧关系吸附轨道，关系按钮移至操作区第一位；
- 日期不存在时不保留日期宽度；
- 无释义条目使用紧凑单行，有释义条目使用紧凑双行；
- 长词与极限短语保留可用横滑，普通短语允许完整换行；
- 跨域同形冲突来源显示在一级表项边框右上角；
- 结构性表项、分组、固定栏和关系展开区改为直角或极小圆角，消除切口。

### 固定栏与弹窗

- PIN 导航重新设计为底部工具栏上方的完全不透明、紧凑、直角次级栏；
- 标注审阅栏使用同一底部停靠体系，不覆盖标题；
- 固定弹窗使用 iOS 背景锁定和滚动边界拦截，滑动不会传递给主页面；
- 查询总入口图标保持不变；仅重绘小弹窗内 Oxford 与 ChatGPT 图标，并缩小弹窗；
- 搜索及表单窗口的输入框、选项和按钮统一等宽对齐。

### 数据、AI 与导入

- 保留 Backup Schema 5、IndexedDB DB version 4、Seed revision 3、VIX 1；
- AI 请求支持 Abort，过期结果不覆盖新编辑，一次任务只生成一条聚合 Undo；
- 人工标注变更不会被 AI 历史错误吸收；
- 增量导入等待数据库事务完成，导入计划继续使用 Revision 防过期保护；
- 调整普通词表优先级会重新计算投影、计数、搜索和跳转，但不迁移 Entry 的 PIN、标注或学习日期。

## 平台与数据

- 主平台：iPhone standalone PWA；
- 数据：本地 IndexedDB；
- 无账户、云同步或远程业务数据库；
- 独立域：2；Entry：6,126；Membership：8,072；
- 全局唯一词汇组：5,322；全局词汇实际 Entry 行：5,539；
- 全局唯一短语组／实际行：587。
