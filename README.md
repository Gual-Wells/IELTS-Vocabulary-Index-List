# Vocabulary Index 3.5.2

面向 iPhone Safari“添加到主屏幕”场景的本地优先英语词汇与短语索引。

## 版本定位

3.5.2 以唯一可信的 `3.5.1 Clean Rebuild` 完整包为基线，只收口真机截图确认的布局、滚动、弹窗与页面状态问题，不改变数据模型和 Seed。

核心原则：

- 系统总表仍是具体 Entry 的特殊投影视图，不拥有独立内容或个人状态；
- 普通词汇继续由同域最高优先级普通词表唯一显示，短语仍按全部 Membership 显示；
- 普通词表继续使用词汇／短语两个独立页面；
- 普通页面切换统一初始化，真实递归返回才恢复完整页面快照；
- 页面稳定性优先于动效，不对滚动、高度、sticky 位置或关系展开使用平滑追赶。

## 3.5.2 当前增量

### 一级表项

- 序号、词汇信息栈和控件信息栈分别纵向居中；
- 繁体释义只扩展词汇区，独立域来源只扩展控件区；
- 删除来源存在时生成的隐藏释义占位；
- 来源使用与繁体释义一致的次级行指标，单行右对齐并省略；
- 序号始终独立纵向居中。

### 顶部、字母轨道与日期组

- sticky 小标题与顶部有效底边零缝隙；
- 字母轨道横滑后进入人工锁定，页面顶部 A 和页面底部 # 均不会因边界回弹立即吸回；
- 只有纵向阅读真实进入新的 sticky 字母后，自动跟随才重新接管；
- 日期模式中的具体“日”和“未标注”可以展开／收起，年和月保持结构标题。

### 页面状态

- 字母／日期切换：目标模式顶部、全部分组收起；
- 词汇／短语切换：目标页面顶部、全部分组收起；
- 搜索、关系、PIN 和手动浏览锚点继续按目标 Entry 展开并定位；
- 左上角、浏览器返回和 iOS 边缘返回恢复离开页面的 view kind、mode、日期月份、滚动、展开组和关系。

### 长按、底栏和弹窗

- 浏览锚点长按达到阈值后先保存，抬手后才显示 Toast；
- Toast 禁止 iOS 文本选择和触控菜单；
- 底部工具栏试行固定 58px，删除独立安全区白带；
- 禁用按钮只灰化图标，结构分隔线保持原色；
- native dialog 使用稳定全屏根层，只有内部卡片跟随 VisualViewport；
- 查询菜单和关系目标菜单共同避让顶部与底部停靠区。
