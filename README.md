# Vocabulary Index 3.5.1

面向 iPhone Safari“添加到主屏幕”场景的本地优先英语词汇与短语索引。

## 版本定位

3.5.1 直接基于 3.5.0 稳定主体，清洁重建真机弹窗、模式切换、字母跟随、浏览锚点和一级表项元信息。两份旧 3.5.1 包已废弃，不得作为代码参考。

核心原则：

- 系统总表仍是具体 Entry 的特殊投影视图，不拥有独立内容或个人状态；
- 普通词汇继续由同域最高优先级普通词表唯一显示，短语仍按全部 Membership 显示；
- 普通词表拆分为词汇视图与短语视图，不再在同一页面同时渲染两套导航；
- 页面稳定性优先于动效，不对滚动、高度、sticky 位置或关系展开使用平滑动画。

## 3.5.1 当前增量

### 交互与布局

- 所有主要弹窗使用统一视觉视口 Shell，标题物理居中，内部控件不再右侧截断；
- 仅弹窗 Body 可滚动，固定区手势不再穿透主页面；
- 字母／日期模式切换只保持当前明确可见 Entry，否则回顶部，不再读取目标模式旧位置；
- 底部第一项改为手动浏览锚点：短按跳转，长按保存，滚动不自动覆盖；
- 字母栏在首尾警戒位提前跟随，使用即时定位、方向滞回和 A/# 硬边界；
- 字母标题和字母导航继续使用 3.5.0 完整展开链，并纳入运行时符号测试；
- 繁体释义与英文左边缘对齐，来源独立域位于表项框内右下并与释义共享第二行；
- 无关系条目保留不可见首操作槽，日期与其余控件对齐；
- 日历外侧双箭头按年、内侧单箭头按月。

### 稳定主体

- 普通词表词汇／短语双视图、五项底部工具栏、内部返回栈、PIN／标注底部停靠栏保持 3.5.0 结构；
- 普通词汇继续使用词表优先级占有；
- Backup Schema 5、DB 4、Seed revision 3、VIX 1 保持不变。

## 本地运行

必须通过 HTTP(S) 打开：

```bash
python3 -m http.server 8000
```

## 自动测试

```bash

```

自动测试不能替代真实 iPhone 对 sticky、惯性滚动、弹窗锁定、底部停靠栏、外部 App 返回和 PWA 生命周期的验收。
