# 3.0.0 RC2 人工验收清单

## 升级前

- [ ] 在 2.4.1 或当前 3.0 中导出完整 JSON，并保存到浏览器之外。
- [ ] 关闭同站点其他 Safari 标签页和主屏幕 PWA。
- [ ] 确认未清除 Safari 网站数据。

## 首次启动与迁移

- [ ] 页面正常启动，迁移提示只显示一次。
- [ ] 默认词域为“通用英语”。
- [ ] A1、A2、B1、B2、C1、AWL、AVL 均存在。
- [ ] 首页总词项为 5,005。
- [ ] 完整 JSON 中 Membership 为 6,407 条且没有 `sourceText`。
- [ ] 旧词性以 `sourceLabel` 保留，不在主行显示。
- [ ] 旧 PIN、PIN 顺序、AI 标注和有效上次位置可用。
- [ ] 旧序号模式保持一致（不显示 / 分组 / 全局）。
- [ ] 再次启动不重复迁移。

## 首页与信息架构

- [ ] 只有“通用英语”一个词域时，首页直接显示七个词表和“短语”，不额外堆叠词域层级。
- [ ] 创建第二词域后，首页自动改为按词域分区。
- [ ] 首页搜索可搜索英文、简体和繁体释义，并跳到正确词表与词项。
- [ ] “管理”Sheet 可新建词域、词表并进入现有词表管理。
- [ ] “系统短语表”在日常界面显示为“短语”，但仍不可删除或重命名。
- [ ] 首页数据安全区可导出和恢复完整 JSON。

## iPhone 交互骨架

建议至少使用 iPhone 13 逻辑宽度 390pt，并分别在 Safari 与主屏幕 PWA 中验证。

- [ ] 词表底部固定显示：搜索、新增、AI 新增、AI 核查、更多。
- [ ] 底部工具栏不覆盖最后一条词项或 Home Indicator。
- [ ] 顶栏返回、撤销、重做和设置可准确点击；词表页不重复显示顶部搜索。
- [ ] 所有高频按钮触控区域足够大，不会频繁误触邻近按钮。
- [ ] 横竖屏切换后页面不出现横向滚动或控件重叠。
- [ ] 系统增大字体后主要按钮与标题仍可用。

## PIN 核心验收

- [ ] 有 PIN 时，独立 PIN 条显示在顶栏下方；无 PIN 时完全隐藏。
- [ ] 滚动到词表中部和底部后，PIN 条仍保持可见与可点击。
- [ ] 点击 `‹` 直接跳到上一个 PIN；点击 `›` 直接跳到下一个 PIN。
- [ ] 跳转完成后 PIN 条仍可继续操作，不需要返回词表顶部。
- [ ] 中间 PIN 文本显示当前词项和计数，点击可重新定位当前 PIN。
- [ ] PIN 条出现时，字母导航停靠在其下方，不相互覆盖。
- [ ] 从搜索、上次位置或标注审阅跳到一个已 PIN 词项时，PIN 计数同步到正确位置。
- [ ] 设置或取消当前词项 PIN 后，PIN 条立即更新。

## 词条与详情 Sheet

- [ ] 单击英文只复制英文文本，并记录上次位置。
- [ ] 未 PIN、无标注的词条右侧只有一个更多按钮，不存在空白禁用按钮。
- [ ] 已 PIN 词条只显示轻量 PIN 状态标签。
- [ ] 有标注时才显示“待核查”，点击进入对应标注。
- [ ] 点击更多打开详情 Sheet，不重置字母展开、滚动位置或整表闪动。
- [ ] 详情正确显示词表来源、相关短语或组成词。
- [ ] 从详情跳到短语或组成词后定位准确。
- [ ] 设置 PIN、编辑、移除当前来源和彻底删除均可正常执行。

## AI 标注与固定面板

- [ ] 标注审阅同时提供上一条和下一条。
- [ ] 取消首项、中间项和末项后进入正确相邻项。
- [ ] 取消标注后当前词条“待核查”立即消失。
- [ ] iPhone 上标注审阅条位于底部工具栏上方，不相互覆盖。
- [ ] AI 核查任务面板在审阅条上方显示；暂停、继续和取消可操作。
- [ ] 同时出现工具栏、审阅条和任务面板时，当前词项仍能滚动到可见区域。

## 词域、词表与短语

- [ ] 新建专业词域后自动出现唯一短语表。
- [ ] 同一英文词可在不同词域分别新增。
- [ ] 同域重复新增只复用 Entry 并增加 Membership。
- [ ] 调整普通词表优先级后，多来源词只显示在新最高优先级词表。
- [ ] 删除一个来源后词项回落；普通词失去全部来源后删除。
- [ ] 新增 `thread pool` 后自动关联同域 `thread` 和 `pool`。
- [ ] `threading` 不会因字符串包含而关联 `thread pool`。
- [ ] 未收录组成词显示“未收录”，之后补录可自动跳转。

## 繁体释义

- [ ] 未启用释义的词域不显示空白释义行或输入框。
- [ ] 启用后“线程池”保存为“線程池”。
- [ ] CSV、JSON、AI 候选入口均只保存规范繁体。
- [ ] 搜索“线程”可命中“線程”。
- [ ] 关闭释义后隐藏但不删除已有释义；重新启用后恢复。

## 数据、撤销和导入

- [ ] 撤销/重做可恢复词项、来源、PIN 和短语索引。
- [ ] TXT/Markdown/CSV/JSON 合并与替换预览正确。
- [ ] “更多”中的导入、导出 CSV、跳到上次位置与管理词表可用。
- [ ] 完整 JSON 导出、恢复、再次导出结构一致。

## Groq

- [ ] 只填 API Key 后可刷新动态模型目录。
- [ ] 刷新后保留历史模型和当前选择。
- [ ] AI 新增候选可导入当前词表。
- [ ] AI 核查支持暂停、继续、取消和部分结果保留。

## PWA 与多实例

- [ ] Safari 与主屏幕 PWA 均显示 3.0.0。
- [ ] 更新后旧 3.0 缓存被 `v3.0.0-rc2` 缓存替换。
- [ ] 飞行模式冷启动可加载应用壳和本地数据。
- [ ] 一个实例修改后另一实例重新载入。
- [ ] 同时写入时至少一方安全取消，而不是静默覆盖。
