# 2.4.0 iPhone Safari / Desktop 真机验收清单

## 版本与首页

- 设置页显示 `Vocabulary Index 2.4.0`。
- 首页显示 7 个词表和 5,005 个全局唯一词汇。
- iPhone 常规宽度下词表为紧凑双列卡片；极窄屏自动变为单列。
- 桌面端词表形成自适应栅格，内容宽度、留白和卡片密度协调。
- 数据维护入口位于词表之后，不抢占首屏主视觉。
- Oxford 主屏幕图标保持原样。

## 字母分组与跳转

- 普通进入 A1、A2、B1、B2、C1、AWL 时所有字母均默认收起。
- 每个词表的 A 都能正常展开并显示实际词条。
- 在 A1 连续交替展开/收起 A、B 十次，不出现空白、随机展开或无响应。
- 从 A1 离开再进入 B1，B1 不继承 A1 展开状态。
- 搜索、PIN、“跳到上次浏览位置”和 AI 标注审阅只展开目标字母。
- 快速依次点击 A1、A2、B1，最终页面为最后点击的词表。

## 模型目录

- 配置 Groq Key 后点击“刷新模型列表”，记录模型数量和刷新时间。
- 关闭设置并重新打开，不发生网络请求也能看到完整缓存目录。
- 刷新后暂时缺失的历史模型仍保留，并标记“未在最近刷新中”。
- 选择模型、关闭页面并重新打开，当前选择仍保留。
- 断网打开设置时，缓存目录仍可使用；刷新失败不清空目录。
- 不要求验证 Qwen 核查兼容性；本版只验收已确认可用模型。

## AI 核查任务

- AWL 小词表核查被拆分为多个或合理单批，界面显示估算、批次和进度。
- A1 或全部词表核查按串行批次运行，不出现并发请求风暴。
- 点击暂停后不再开始新批次；点击继续后从下一待处理批次继续。
- 点击取消后当前请求终止或完成后停止，已完成批次标注仍保留。
- 临时断网、超时或 5xx 时执行有限重试，界面显示等待状态。
- 429 时根据服务端等待时间倒计时，不立即重复请求。
- 接近 token 或 request 额度边界时主动等待。
- 核查期间人工编辑某个尚在请求中的词，该词不得接收陈旧标注。
- AI 核查只生成标注，不直接改词。

## 标注审阅

- 核查完成后出现“审阅标注”按钮和准确数量。
- 首页显示所有词表待审阅总数；词表页只显示当前词表数量。
- 点击审阅后自动打开第一条目标词所在字母，并滚动、高亮目标行。
- 上一条/下一条可以跨字母、跨词表跳转。
- 点击编辑并保存后，陈旧标注消失，审阅列表继续到有效条目。
- 点击取消标注后自动进入下一条；处理完全部标注后退出审阅。
- 审阅条目被其他操作删除时，不崩溃并自动从列表剔除。
- 退出审阅后 PIN 导航恢复显示。

## 复制、数据与关联操作

- 单词、撇号词、连字符词、逗号词和短语均完整复制。
- 新增、编辑、删除、撤销、重做正常。
- 将一个词改名为已存在词时，来源和词性合并，全局仍只有一条。
- 删除较早来源后，词自动回落到下一优先词表，PIN 随归属移动。
- 快速连续固定/取消 PIN，不产生重复 PIN。

## 导入、初始化与备份

- 异常 CSV 只显示错误，不修改数据。
- 合并导入和替换导入的预览统计与提交结果一致。
- 导出完整 JSON，恢复该文件后业务数据一致。
- 初始化 seed 后首页恢复 5,005 词；撤销可恢复初始化前状态。
- 导出文件不包含 Groq Key 或缓存模型目录。

## 多实例、PWA 与缓存

- Safari 标签页修改一个词后，主屏幕 PWA 载入最新状态或拒绝陈旧写入，不得静默覆盖。
- 添加到主屏幕后 standalone 启动。
- 飞行模式下可冷启动、浏览、编辑和英语搜索。
- 发布新版本后设置页版本正确，不出现旧 HTML 与新 JS 混用。
- 快速连续点击同一个对话框入口，不出现 `showModal` 错误。
