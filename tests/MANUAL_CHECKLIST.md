# 2.2.1 iPhone Safari 真机验收清单

## 版本与初始数据

- 设置页显示 `Vocabulary Index 2.2.1`。
- 首页显示 7 个词表和 5,005 个全局唯一词汇。
- Oxford 主屏幕图标保持原样。
- 首页不显示 GitHub、云同步、PAT 或远端快照相关控件。

## 字母分组

- 普通进入 A1、A2、B1、B2、C1、AWL 时所有字母均默认收起。
- 在每个词表展开 A 后均能看到实际词条。
- 在 A1 连续交替展开/收起 A、B 十次，不出现空白、随机展开或无响应。
- 从 A1 离开再进入 B1，B1 不继承 A1 的展开状态。
- 搜索结果、PIN 和“跳到上次浏览位置”只展开目标字母。
- 快速依次点击 A1、A2、B1，最终页面必须是最后点击的词表。

## 复制流程

- 单词、撇号词、连字符词、逗号词和短语均完整复制。
- 快捷指令打开牛津辞书后可以手工粘贴。
- 拒绝剪贴板权限后，兼容复制路径仍有明确成功或失败提示。

## 数据与关联操作

- 新增、编辑、删除、撤销、重做正常。
- 将一个词改名为另一个已存在词时，来源和词性合并，全局仍只有一条。
- 人工改名后再从另一词表导入同名词，完整 JSON 仍能成功导出和恢复。
- 删除较早来源后，词自动回落到下一优先词表，PIN 也随归属移动。
- 快速连续点击固定/取消 PIN，不产生重复 PIN。
- 调整词表优先级后计数、搜索标签、PIN 和导出数据一致。

## 导入、初始化与备份

- 异常 CSV 只显示错误，不修改数据。
- 合并导入和替换导入的预览统计与提交结果一致。
- 导出完整 JSON，恢复该文件后业务数据一致。
- 恢复完整 JSON后立即撤销、重做，数据均可往返。
- 初始化 seed 后首页恢复 5,005 词；撤销可恢复初始化前状态。
- 清理浏览器网站数据前能够将 JSON 保存到“文件”或其他外部位置。

## 多实例与生命周期

- 在主屏幕 PWA 打开编辑框，短暂切到其他 App 再返回；若没有其他实例修改，编辑框不应被无故关闭。
- Safari 标签页修改一个词后，主屏幕 PWA 应载入最新状态或拒绝陈旧写入，不得静默覆盖。
- 不建议在两个实例中高频同时编辑；测试后只保留一个主实例。

## PWA 与缓存

- 添加到主屏幕后 standalone 启动。
- 飞行模式下可冷启动、浏览、编辑和英语搜索。
- 发布新版本后设置页版本正确，不出现旧 HTML 与新 JS 混用。

## AI

- 读取模型列表、中文联想、AI 新增和 AI 核查正常。
- AI 核查只生成标注，不直接修改词条。
- 修改输入、切换范围、关闭或取消请求后，旧响应不再写回界面。
