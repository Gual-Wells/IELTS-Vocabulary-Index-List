## 2. 普通进入、普通切换和递归返回

### 普通进入／切换

- [ ] 从首页进入任一词表：页面顶部、全部字母收起；
- [ ] 词汇 → 短语：目标页面顶部、全部标题收起，不恢复该页面旧位置；
- [ ] 短语 → 词汇：同上；
- [ ] 字母 → 日期：目标模式顶部，具体日和“未标注”全部收起；
- [ ] 日期 → 字母：目标模式顶部，全部字母收起；
- [ ] 上述普通切换不读取或覆盖手动浏览锚点；
- [ ] 反复切换 20 次后始终稳定回到目标页顶部，不产生累计漂移；
- [ ] 系统总表的词／短语切换按钮保持原槽位并灰度禁用。

### 目标跳转

- [ ] 搜索、关系、PIN、标注和手动浏览锚点跳转仍只展开目标组并定位具体 Entry；
- [ ] 同页目标跳转和跨词表目标跳转均有效；
- [ ] 目标跳转不会额外展开无关字母、日期或关系。

### 递归返回

- [ ] 在来源页中部展开一个组和若干关系后跳往下级页面，再使用左上角返回：恢复来源 Collection、词／短语页、字母／日期模式、日期月份、滚动、展开组和展开关系；
- [ ] 浏览器返回与 iOS 边缘返回使用同一恢复规则；
- [ ] 返回不会直接跳回首页，也不会形成重复历史循环；
- [ ] 普通词／短语或字母／日期切换不新增一层历史。

## 3. 一级表项四组合布局

分别在无序号、有组序号、有全局序号三种模式下检查：

- [ ] 无繁体释义／无来源；
- [ ] 有繁体释义／无来源；
- [ ] 无繁体释义／有来源；
- [ ] 有繁体释义／有来源。

统一要求：

- [ ] 序号始终独立纵向居中；
- [ ] 英文与可选繁体释义构成左侧独立信息栈并整体纵向居中；
- [ ] 日期、五个操作槽与可选独立域来源构成右侧独立信息栈并整体纵向居中；
- [ ] 一侧增加次级信息时不会在另一侧生成隐藏占位；
- [ ] 繁体释义和来源字号、行高、颜色一致；来源单行右对齐，超长时省略；
- [ ] 无变化的一侧仍按自身内容居中，不被另一侧强制上移；
- [ ] 表项最终高度由真实较高内容决定，无不必要第三档膨胀；
- [ ] 英文、短语和繁体释义均完整可访问；超长英文横滑，短语按既有规则换行／横滑；
- [ ] 操作顺序仍为关系、日期、PIN、查询、更多；无关系时首槽不可见但保留对齐。

## 4. 顶部接缝、字母轨道和 sticky 标题

- [ ] 顶栏／字母栏底边与 sticky 字母标题完全贴合，没有可透出正文的细长缝隙；
- [ ] 快速滚动时正文、边框和控件不会从接缝闪现；
- [ ] sticky 使用真实标题本身，无复制悬浮标题、毛玻璃或平滑追赶；
- [ ] 下一标题自然推出上一标题；
- [ ] 点击标题可展开／收起，折叠后标题视觉位置稳定；
- [ ] 首次展开立即生成正文，不需要第二次点击；
- [ ] 页面顶部横滑字母轨道到中后段，松手后不会按固定延迟回到 A；
- [ ] 页面保持静止时字母轨道继续保持用户定义位置；
- [ ] 页面底部处于 # 时把字母轨道横滑回中段，松手及底部橡皮筋回弹后都不立即吸回 #；
- [ ] 纵向滚动使真实标题触及 sticky 边界且活动字母真正改变后，自动跟随才重新接管；
- [ ] 点击某字母时立即释放人工锁、展开并定位；
- [ ] 正向／反向快速惯性滚动、A/# 边界和橡皮筋回弹无明显抖动或迟滞；
- [ ] sticky 触发及时，不出现长期未触发或明显延后才出现。

## 5. 日期模式和折叠

- [ ] 切入日期模式时，有学习日期则日历显示最新学习月份；完全无学习日期则显示当前月份；
- [ ] 年／月只作为结构标题，不折叠；
- [ ] 每个具体日标题和“未标注”标题均可展开／收起，并显示数量和箭头；
- [ ] 收起 sticky 日标题时阅读锚点稳定，不发生大幅跳动；
- [ ] 日历点击某一天时自动展开对应日期组并定位；
- [ ] 刷新某 Entry 日期后，目标日期组自动展开并保持 Entry 可见；
- [ ] 返回快照可以恢复日期月份及已展开日期组。

## 6. 浏览锚点长按

- [ ] 短按有锚点时跳转，无锚点时只提示；
- [ ] 长按约 520ms 保存成功，但在手指仍按住时不弹出可选中的 Toast；
- [ ] 抬手后才显示“已保存当前位置”；
- [ ] 连续长按 20 次均不出现蓝色文本选择手柄或 iOS 触控菜单；
- [ ] 达到保存阈值后发生 `pointercancel`：保存结果保留，但不显示成功 Toast；
- [ ] 阈值前移动、滚动或 `pointercancel` 不保存；
- [ ] 普通滚动、搜索、PIN、关系和返回顶部不会自动改写锚点。

## 7. 底部工具栏与次级停靠栏

- [ ] 工具栏固定五项，槽位和间距不变；
- [ ] 工具栏试行总高 58px，当前 3.5.1 的独立安全区白带消失；
- [ ] 背景连续到屏幕底部，不出现额外空白断层；
- [ ] 五个按钮均可稳定点击，上滑回主屏幕／切换 App 不发生明显误触；
- [ ] 最后一条正文可完整滚出且不被工具栏遮挡；
- [ ] 禁用按钮只灰化图标，按钮分隔竖线和工具栏边界保持正常颜色；
- [ ] PIN／标注栏位于工具栏上方，完全不透明、直角、无重叠；
- [ ] PIN／标注栏出现或消失时正文底部留白同步，无抖动；
- [ ] 键盘出现时底栏和次级栏按既有规则隐藏或避让。

> 若固定 58px 确实与底部系统手势冲突，记录具体误触步骤和录屏；后续只增加真机证明必需的最小避让，不恢复独立白带。

## 8. 所有弹窗和 VisualViewport

逐一检查搜索、设置、词条更多、词表更多、词库管理、导入、确认、AI、关系多目标弹窗：

- [ ] 打开后遮罩覆盖完整屏幕和底部区域，无白带；
- [ ] 首帧没有“先出现—抖动—归位”；
- [ ] 连续打开关闭同一弹窗 20 次，位置稳定；
- [ ] 卡片始终位于当前视觉视口内，横竖边缘不被裁切；
- [ ] 键盘弹出／收起时只有内部卡片重新定位，遮罩根层不跳动；
- [ ] 不可滚动弹窗中的滑动不传给背景；
- [ ] 可滚动弹窗只滚内部，抵达边界后不穿透背景；
- [ ] 关闭后主页面精确回到原 scrollY；
- [ ] 查询菜单和关系目标菜单避让顶部 chrome、底部工具栏、PIN／标注栏。

## 10. 录屏建议

至少保存三段：

1. 首页 → 普通表 → 展开 → 横滑字母轨道 → 纵向滚动触发 sticky → 日期切换 → 返回；
2. 四种表项组合 → 长按保存 → 底栏禁用状态 → PIN／标注栏；
3. 连续打开搜索／设置／管理弹窗 → 键盘 → 关闭 → 关系跳转 → 递归返回。
