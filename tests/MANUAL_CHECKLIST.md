# Vocabulary Index 3.0.0 人工验收清单

验收设备：iPhone 17 标准版 Safari / 主屏幕 PWA；Windows Chrome 辅助。

## A. 发布与版本

- [ ] GitHub Pages 构建成功，无 404。
- [ ] `index.html`、CSS、JS、Manifest、Seed 和图标均能加载。
- [ ] 设置显示版本 3.0.0 / Schema 3。
- [ ] 新版本准备好时出现顶部更新提示。
- [ ] 点击“稍后更新”不会刷新当前操作。
- [ ] 点击“立即更新”只重载一次并进入新版本。

## B. 首次启动与迁移

- [ ] 空浏览器首次启动成功初始化 5,005 个词项。
- [ ] 首页显示 7 个普通词表和短语入口。
- [ ] 2.4.1 原地升级只执行一次。
- [ ] 迁移提示明确要求导出 3.0 JSON。
- [ ] A1/A2/B1/B2/C1/AWL/AVL 数量合理。
- [ ] PIN、标注、序号和上次位置迁移后有效。

## C. 首页视觉

- [ ] 米色背景、墨绿色、Georgia 标题/数字保持统一。
- [ ] iPhone Safe Area 无顶端遮挡。
- [ ] 词表卡片没有永久管理按钮矩阵。
- [ ] 单词域与多词域布局都能直接点卡片进入词表。
- [ ] 短语入口视觉次于普通词表但可发现。

## D. 字母与列表

- [ ] 普通进入词表不自动跳到上次位置。
- [ ] 字母默认折叠。
- [ ] 点击字母标题只展开/收起当前分组。
- [ ] 点击字母导航自动展开并滚动一次。
- [ ] A 和 Z 等大分组展开无明显卡顿。
- [ ] 切换词表不会错误继承另一词表的展开状态。
- [ ] 主列表仅突出英文和当前词表词性。
- [ ] 未 PIN / 无标注词条不保留空白按钮槽。
- [ ] 每行只有一个 `⋯` 管理入口。

## E. 复制与外部词典链路

- [ ] 点词条主体复制英文，不复制词性或释义。
- [ ] 显示短时复制成功提示。
- [ ] 通过快捷指令打开牛津词典并粘贴成功。
- [ ] 从牛津词典返回后滚动位置和展开字母保持。
- [ ] 复制不会打开详情或改变列表状态。
- [ ] Clipboard API 失败时兼容路径可用或给出明确错误。

## F. PIN 连续导航

- [ ] 从词条 `⋯` 设置 PIN 后出现 PIN 控制器。
- [ ] PIN 控制器位于 Topbar 下方并随滚动保持可见。
- [ ] 上一个 / 下一个跳转后控制器仍可立即操作。
- [ ] 点击中间词汇重新定位当前 PIN。
- [ ] 目标字母自动展开。
- [ ] 每次跳转只有一次滚动和一次高亮。
- [ ] 删除或取消 PIN 后计数与当前位置正确。
- [ ] 进入标注审阅时 PIN 隐藏，退出后恢复。

## G. 上次位置

- [ ] 复制后“继续上次位置”定位到复制词。
- [ ] 手动滚动停止后记录稳定可见词条。
- [ ] 手动滚动记录不会在 PIN/搜索动画中覆盖目标。
- [ ] 普通进入不自动强制恢复。
- [ ] 用户主动恢复时展开目标字母并单次定位。

## H. 搜索

- [ ] 当前词表、当前词域和全部范围正确。
- [ ] 英文输入即时返回结果。
- [ ] 轻微拼写错误可命中合理结果。
- [ ] 中文本地释义检索可用。
- [ ] AI 中文联想只在主动点击后请求。
- [ ] 输入变化或关闭后旧 AI 结果不覆盖新状态。
- [ ] 点击结果跨词表定位正确且只滚动一次。
- [ ] iPhone 虚拟键盘不遮挡输入和结果关键区域。

## I. 动作、详情与编辑

- [ ] `⋯` 打开动作菜单，不直接展开详情。
- [ ] “查看详情”使用独立只读容器。
- [ ] 详情显示来源、可选释义、相关短语/组成词。
- [ ] 编辑词性只影响当前词表 Membership。
- [ ] 同域重名编辑被拒绝。
- [ ] 从当前词表移除与彻底删除语义清楚。
- [ ] 危险操作必须二次确认。
- [ ] 弹窗验证失败后保留输入和弹窗。

## J. 导入、备份、恢复

- [ ] TXT、Markdown、CSV、JSON 数组分别预览。
- [ ] 格式错误不会清空原词表。
- [ ] 合并导入对同词词性去重合并。
- [ ] 替换导入可撤销。
- [ ] 当前词表 CSV 导出可打开。
- [ ] 完整 JSON 包含全部业务实体。
- [ ] Groq API Key 不进入完整 JSON。
- [ ] 3.0 JSON 恢复成功并清空旧撤销历史。
- [ ] 恢复前警告和备份提示明确。

## K. AI 模型与新增

- [ ] API Key 只保存于当前浏览器。
- [ ] 模型目录只有点击刷新才联网。
- [ ] 刷新后历史模型仍保留并标记。
- [ ] 选择模型保存后重开仍存在。
- [ ] AI 新增返回结构化候选并先预览。
- [ ] 候选导入仍执行域内去重和词性合并。
- [ ] 不同模型失败时按实际 API 错误处理，不按名称分支。

## L. AI 核查与标注

- [ ] 启动前显示词表、数量、批次和模型。
- [ ] 核查不直接修改词条。
- [ ] 任务面板显示进度。
- [ ] 暂停在当前请求结束后停止推进。
- [ ] 继续恢复后续批次。
- [ ] 取消保留已完成批次标注。
- [ ] 收起后只显示临时任务胶囊。
- [ ] 点击胶囊恢复任务面板。
- [ ] 审阅有上一条、下一条、编辑、取消和退出。
- [ ] 跨词表审阅定位正确。
- [ ] 取消首项、中间项和末项后进入正确相邻项。

## M. PWA、离线与多实例

- [ ] 添加到主屏幕后图标、名称和状态栏正确。
- [ ] 完整在线加载后开启飞行模式可冷启动。
- [ ] 离线浏览、复制、PIN、搜索和编辑可用。
- [ ] 离线 AI 明确报网络错误，不破坏任务数据。
- [ ] Safari 标签页修改后主屏幕 PWA收到变化通知。
- [ ] 主屏幕 PWA 修改后 Safari 标签页重新加载状态。
- [ ] 并发陈旧编辑被阻止，不静默覆盖。
- [ ] 后台冻结、系统回收、重新打开后数据完整。

## N. Windows Chrome

- [ ] 宽屏布局不拉长到不可读。
- [ ] 鼠标、键盘 Tab 和 Enter 操作正常。
- [ ] `:focus-visible` 清晰。
- [ ] 搜索、编辑、导入和备份可用。
