# 3.5.1 iPhone 主屏幕 PWA 人工验收清单

> 3.5.1 在 3.5.0 稳定主体上收口弹窗、模式切换、浏览锚点、字母栏和一级表项。逐项记录机型、iOS 版本、数据状态、复现步骤和录屏时间点。自动测试不能替代本清单。

## 安装、升级与生命周期

- [ ] 冷启动显示 3.5.1，Service Worker 不再提供 3.4.0 旧资源；
- [ ] Schema 5 数据直接打开，Entry、Membership、PIN、标注和学习日期不丢失；
- [ ] 从后台、锁屏、Oxford 和 ChatGPT 返回后，当前页面、视图、滚动位置和展开状态保持；
- [ ] 更新提示、立即更新、关闭并重新打开均正常；
- [ ] 状态栏、灵动岛与 Home Indicator 安全区正确。

## 页面入口与返回栈

- [ ] 从首页进入普通词表：默认词汇视图、页面顶部、全部字母收起；
- [ ] 从首页进入系统总表：对应固定 kind，页面顶部、全部字母收起；
- [ ] 从搜索结果进入：其他字母收起，只展开目标组并精确定位；
- [ ] 从关系跳转进入：其他字母收起，只展开目标组并精确定位；
- [ ] 同一词表、同一视图内的跳转仍执行展开和定位；
- [ ] 跨词表跳转后左上角返回，恢复来源词表、view kind、排序模式、滚动、字母和关系展开状态；
- [ ] 浏览器／iOS 边缘返回与左上角返回行为一致；
- [ ] 返回链不会直接跳回首页，也不会形成重复首页循环；
- [ ] 词汇／短语视图切换不额外污染浏览器历史。

## 普通表词汇／短语双视图

- [ ] 普通表不再同页渲染词汇区和短语区；
- [ ] 底部第四项在词汇／短语间切换；
- [ ] 两个视图分别保存字母／日期模式、滚动位置、展开字母和关系展开；
- [ ] 只有词汇或只有短语的普通表仍可切换到另一空视图；
- [ ] 空视图保留当前规范标题、模式、禁用字母和空状态；
- [ ] 0→1 新增第一项和 1→0 删除最后一项后，空状态与导航立即更新；
- [ ] 系统总表切换按钮灰色禁用。

## 底部工具栏与 PIN／标注停靠栏

- [ ] 底部工具栏固定五项：上次位置、顶部、排序、词／短语、搜索；
- [ ] 工具栏完全不透明、直角、与安全区融合，不遮挡最后一行；
- [ ] 键盘出现时底部工具栏隐藏或正确避让；
- [ ] PIN 导航使用新的紧凑直角底部次级栏，不沿用 3.4.0 毛玻璃／药丸样式；
- [ ] PIN 栏位于底部工具栏上方，不遮挡标题、字母栏或正文；
- [ ] PIN 栏左右切换和当前定位正常，出现／消失时正文底部留白同步；
- [ ] 标注审阅栏使用同一底部停靠体系，不透出背景；
- [ ] PIN 与标注状态同时存在时无重叠、跳动或错误点击层。

## 字母栏与真实 sticky 小标题

- [ ] 字母栏只包含 A–Z/#，不再混入固定工具控件；
- [ ] 当前字母变化后选中态即时更新，无明显延迟；
- [ ] 当前字母不在可视区时使用无动画 nearest 带入；
- [ ] 回到 A 时轨道准确归零，到 # 时准确到末端；
- [ ] 用户横向拖动字母栏期间暂停自动校正，结束后立即同步；
- [ ] 真实小标题本身 sticky，不创建复制标题；
- [ ] sticky 小标题与原始小标题样式完全一致、完全不透明、无毛玻璃；
- [ ] 下一标题自然推出上一标题；
- [ ] 点击 sticky 小标题收起该组，标题本身不发生明显位置跳跃；
- [ ] 首次展开立即渲染，不需要再次点击，不出现长延迟；
- [ ] 日期模式没有误用字母折叠／sticky 行为。

## 一级表项静态布局

- [ ] 结构性一级表项为直角或极小圆角，不再与外框形成残缺切口；
- [ ] 序号作为英文前置文本，不显示独立序号框，也不预留永久序号轨道；
- [ ] 无序号时完全不占序号空间；
- [ ] 日期未标注时日期区域宽度为零，控件不侵占文本区；
- [ ] 操作顺序为关系、日期、PIN、查询、更多；无关系时不留空轨道；
- [ ] 无繁体释义条目接近字母小标题高度；
- [ ] 有释义条目采用紧凑双行，总高度明显低于 3.4.0；
- [ ] 跨域冲突来源副字位于表项边框右上角，不在词汇正文区内；
- [ ] 来源副字不覆盖日期、按钮、英文或释义；
- [ ] 控件间距缩紧但每个触控区可靠，无相互覆盖。

## 长词、短语和横滑

- [ ] 3.4.0 录屏中只剩竖线／图标的条目已恢复完整正文；
- [ ] `key management` 等短语完整显示，关系展开后不被裁切；
- [ ] 普通单词单行，真正超长时可横滑；
- [ ] 普通短语允许自然换行；两行仍溢出时升级为极限布局；
- [ ] 极限短语可横滑且完整可访问，不显示省略号；
- [ ] 节点绑定新 Entry、切换视图／模式、重新物化后 scrollLeft 归零；
- [ ] 横滑后不误触复制，纵向滚动不被误判为横滑；
- [ ] Chunk 物化、关系展开和短语升级不把当前视口明显推走；
- [ ] 长距离滚动没有持续空白块、跳高或条目突然替换闪动。

## 关系与跳转

- [ ] 关系展开按钮位于操作区第一项，不再使用右侧吸附轨道；
- [ ] 展开面板与一级表项形成连续直角结构，无边缘切口；
- [ ] 唯一域内目标显示域内图标并直接跳转；
- [ ] 唯一域外目标显示域外图标并直接跳转；
- [ ] 两个及以上目标显示多目标图标；
- [ ] 多目标弹窗为紧凑扁平列表，按独立域顺序、词表优先级和分区稳定排序；
- [ ] 只列出真实可见目标，不出现“位置已失效”；
- [ ] 同页面关系跳转有效；跨页面跳转后返回状态正确；
- [ ] 关系展开状态按 collection + view kind + entry 隔离。

## 搜索与查询

- [ ] 顶部词表页不再显示搜索按钮；底部第五项打开搜索；
- [ ] 搜索弹窗整体居中，文本框、范围选项和按钮左右边缘等宽对齐；
- [ ] 搜索弹窗打开时不自动弹键盘；
- [ ] 搜索范围先限定再排序，不漏掉当前词表结果；
- [ ] 全局跨域同形 Entry 可分别通过英文和繁体释义搜索；
- [ ] 查询总入口图标保持既有正确图形；
- [ ] 仅 Oxford 与 ChatGPT 弹窗图标已重绘，尺寸、线宽和视觉重量一致；
- [ ] 查询选择弹窗明显小于 3.4.0，锚定正确并避让边缘；
- [ ] Oxford／ChatGPT 返回后页面状态保持。

## 弹窗与背景滚动锁

- [ ] 所有固定不可滚动弹窗中，上下滑动不会移动后方主页面；
- [ ] 可滚动弹窗内容只滚动内部，抵达边界后不把手势传给背景；
- [ ] 关闭弹窗后主页面精确回到原 scrollY；
- [ ] 搜索、编辑、管理、导入、AI 设置、多目标和危险确认均通过；
- [ ] 弹窗标题、输入、选项和按钮对齐，无明显不等宽；
- [ ] 固定表面完全不透明，无背景穿透。

## 视觉基线

- [ ] 页面不再有廉价浅绿大面积背景、方向渐变、玻璃光晕或结构阴影；
- [ ] 首页左侧装饰竖线已移除；
- [ ] 目标高亮不再出现首部短竖线；
- [ ] 顶栏、字母栏、底部栏、分组、表项和关系区按规范使用直角；
- [ ] 独立按钮和弹窗仅保留克制的小圆角；
- [ ] 顶栏标题严格视觉居中；
- [ ] 页面／视图切换只使用轻量透明度过渡，无滚动、高度或 sticky 动画。

## 优先级占有与状态关联

- [ ] 同域普通词汇有多个 Membership 时，只在最高优先级普通词表显示；
- [ ] 调整词表优先级后，重叠词汇立即宏观重新归属；
- [ ] 调整优先级同步更新普通表计数、搜索范围、关系目标、PIN 可见上下文、字母／日期分组和序号；
- [ ] 优先级变化不迁移或合并 Entry 的 PIN、标注、学习日期和释义；
- [ ] 短语仍在全部普通 Membership 中分别显示；
- [ ] 失效上次位置被清理，不按跨域同形词偷换到另一个 Entry。

## PIN、标注、日期和 AI

- [ ] PIN、标注和学习日期绑定具体 Entry，在各投影视图同步；
- [ ] 跨域同形 Entry 的个人状态彼此独立；
- [ ] 刷新日期后 Entry 移到正确日期组并保持可见；
- [ ] AI 运行期间人工撤销／编辑标注不会被后续批次重新覆盖；
- [ ] AI 旧文本结果不写回，也不删除原有有效标注；
- [ ] 点击取消立即中断当前 Fetch 和重试等待；
- [ ] 一次 AI 任务只产生一条 Undo，撤销不影响正文、PIN、日期或任务期间人工标注操作；
- [ ] 数据操作中止 AI 后，已产生标注与历史状态一致。

## 导入与数据安全

- [ ] 增量导入等待数据库事务真正结束后才关闭流程；
- [ ] 导入计划 Revision 过期时重新预检；
- [ ] 歧义 VIX 裸键不猜测，跳过并在报告中列出；
- [ ] 高危操作先选择下载／不下载备份，两条路径都继续正式确认；
- [ ] 完整恢复后取消所有旧页面异步回调并一次性重建视图；
- [ ] 备份导出、恢复和 VIX 交换的数据数量一致。

## 性能与录屏复验

- [ ] 打开全局词汇总表无长白屏；
- [ ] 展开大型字母组无明显冻结；
- [ ] 字母选中框不再追不上主列表；
- [ ] 位置恢复不再“先定位、后插入内容、再被推走”；
- [ ] 慢速与快速滚动均无持续跳动；
- [ ] PIN／标注停靠栏出现时页面不重新抖动；
- [ ] 重新录制至少一段：首页→普通表→展开→关系跳转→返回→词／短语切换→搜索→弹窗滑动；
- [ ] 将录屏与 3.4.0 灾难录屏逐项对照。


## 3.5.1 定向复验

- [ ] 搜索、设置、管理词库、条目操作、数据交换和确认弹窗均物理居中，右侧无截断，底部遮罩覆盖 Home Indicator 区域；
- [ ] 搜索标题物理居中，输入框和范围下拉框左右边缘一致；
- [ ] Large Title、日历顶部和页面顶部切换模式时从顶部开始，不取得下方刚露出的 Entry；
- [ ] 有明确可见 Entry 时切换模式能保持该 Entry；
- [ ] 靶心短按跳转、长按保存；长按过程中移动手指或滚动页面会取消；滚动、复制和返回顶部不覆盖锚点；
- [ ] 字母选中按钮进入首尾警戒位时轨道提前移动；快速正反滚动无临界抖动；手动横滑结束后选中按钮回到可视区；
- [ ] 序号开启时繁体释义与英文左边缘对齐；
- [ ] 有／无关系条目的日期和固定按钮严格对齐；
- [ ] 跨域来源位于真实第二元信息行右下角，不覆盖释义或控件；有来源与有释义使用同一双行高度；
- [ ] 日历外侧双箭头跳年，内侧单箭头跳月，当前月份保持。
