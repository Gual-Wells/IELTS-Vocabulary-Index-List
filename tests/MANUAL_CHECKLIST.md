# Vocabulary Index 3.0.7 人工验收清单

## 首页与词域

- [ ] 全局层、通用英语、计算机术语使用独立而轻量的视觉容器。
- [ ] 全局固定显示全局总表和全局短语表。
- [ ] 每个词域固定显示总词表和短语，其后才是普通词表。
- [ ] 计算机术语显示四个普通词表，数量分别为 214、197、114、19。
- [ ] 四个普通词表数量之和为 544。
- [ ] 管理器和搜索范围不出现“内置来源”。

## 日常浏览

- [ ] 点英文复制；关系、PIN、更多各自使用独立控件。
- [ ] 短语组成词跳到普通词表而非总词表。
- [ ] 搜索、关系、上次位置和 PIN 的目标高亮清楚。
- [ ] 键盘开关不造成背景页面剧烈跳动。
- [ ] 连续浏览、PIN 和关系操作没有浏览器未响应。

## 数据交换

- [ ] 首页设置中只有一个“数据交换”入口。
- [ ] 功能下拉包含内容导入、内容导出、完整备份、完整恢复。
- [ ] 范围下拉包含全局、独立域、词表。
- [ ] 词表目标不包含全局表或词域总词表。
- [ ] 独立域和词表下拉会随范围正确切换。
- [ ] 增量合并预检不报告隐式删除。
- [ ] 完整替换显示明确危险动作文字。
- [ ] 文件目标与面板目标不一致时出现选择项。
- [ ] 导入确认前自动下载恢复备份。
- [ ] 差异预览返回后原选择和文件仍保留。
- [ ] `data/examples/` 中的新词域、词表增量、短语增量示例均可通过预检。
- [ ] 大型文件预检期间页面仍可响应，不出现浏览器未响应提示。

## 更新与恢复

- [ ] 从 3.0.5 升级后只补充四个分类词表，不重复插入计算机术语。
- [ ] 原 PIN、标注、浏览位置和用户自建内容保留。
- [ ] 更新提示激活后只刷新一次。
- [ ] 完整备份和完整恢复正常。
