# 3.3.1 iPhone 主屏幕 PWA 人工验收清单

> 目标设备：iPhone Safari 添加到主屏幕后运行。逐项记录机型、iOS 版本和结果。

## 安装、状态栏与生命周期

- [ ] 冷启动版本显示 3.3.1；
- [ ] 页面背景与状态栏自然衔接；
- [ ] 标题、按钮、弹窗和输入框不侵入时间、灵动岛或信号区域；
- [ ] Home Indicator 不遮挡底部窗口和按钮；
- [ ] 锁屏 2–10 分钟后返回，页面宽度和缩放不异常；
- [ ] 从 Oxford／ChatGPT 返回后，当前位置和页面宽度保持；
- [ ] Service Worker 更新提示、立即更新和完全重启正常。

## 动态顶部与首页

- [ ] 页面顶部显示滚动大标题；
- [ ] 向下滚动后固定紧凑标题继续显示返回／搜索／更多；
- [ ] 应用内从词表返回首页恢复离开首页前的位置；
- [ ] 冷启动首页仍从顶部开始；
- [ ] 首页存在标注时，黄色警告条覆盖出现且不推动卡片；
- [ ] 黄色警告条主体无交互、无关闭按钮；
- [ ] “全部撤销”立即清除全局标注并使警告条消失。

## 字母、日期与跳转

- [ ] 固定工具按钮与横向 A–Z 轨道互不覆盖；
- [ ] “返回上次位置”没有虚影或重叠边框；
- [ ] 全局词汇总表的字母／日期模式均可恢复上次位置；
- [ ] 全局短语总表的字母／日期模式均可恢复上次位置；
- [ ] 域内总表和普通表词汇／短语区的位置互不污染；
- [ ] 字母小标题跳转后位于动态顶部下方；
- [ ] 年、月、日、未标注和词汇／短语区标题跳转后位于动态顶部下方；
- [ ] 搜索、PIN、关系和上次位置目标位于上部阅读区；
- [ ] 词表返回顶部按钮始终存在，到顶部时仅降低强调度。

## 普通词汇一级表项

- [ ] 一级表项为紧凑横向结构，不再使用独立操作行；
- [ ] 英文固定一行，繁体释义固定一行副字；
- [ ] 英文与释义共同横向滑动；
- [ ] 超长词不省略、不换行、不挤压日期或操作控件；
- [ ] 轻点复制；发生实际横滑后不误复制；
- [ ] 纵向滚动不会频繁误触横滑；
- [ ] 日期显示为当前年 `月·日`、非当前年 `两位年·月·日`；
- [ ] 日期刷新、PIN、查询和更多位置稳定；
- [ ] 序号框贴附左边框并保持屏幕安全留白；
- [ ] 三位和四位序号不覆盖英文；
- [ ] 序号按页面实际渲染顺序连续。

## 短语一级表项

- [ ] 常规短语单行完整显示；
- [ ] 较长短语缩小字号并最多显示两行；
- [ ] 两行短语提高高度但不形成第二条完整操作栏；
- [ ] 极限短语约为标准表项 1.5 倍高；
- [ ] 极限短语上部短语与繁体释义共同横滑；
- [ ] 极限短语下部只排列实际存在的日期和控件；
- [ ] 未显示内容不留空位，元素变化后当前功能区重新平均分布。

## 关联

- [ ] 所有一级表项主体内部几何一致；
- [ ] 有关联时右侧出现细长附着件；
- [ ] 无关联时附着件不显示，但正文、日期和控件位置不变；
- [ ] 收起图标向右、展开图标向下，造型与全套图标一致；
- [ ] 展开关联不导致当前一级表项突然跳离视口；
- [ ] 二级表项文字复制正常；
- [ ] 二级跳转按钮外观统一，域内、域外和全局下钻正确。

## PIN 与标注

- [ ] 首个 PIN 设置时顶部 PIN 条覆盖进入，页面不跳动；
- [ ] 最后一个 PIN 取消时页面不跳动；
- [ ] PIN 上一条／下一条正常；
- [ ] 被标注表项显示低强度红色边缘渐变；
- [ ] 点按被标注表项进入处理，不复制；
- [ ] 被标注表项的 PIN、查询、更多和关联仍可独立使用；
- [ ] 标注上一条／下一条正常；
- [ ] “撤销当前词表全部标注”立即执行并关闭空审阅队列。

## 查询菜单

- [ ] 一级表项只显示一个查询按钮；
- [ ] 点击后出现带尖角的双图标小菜单；
- [ ] 菜单尖角准确指向触发按钮；
- [ ] 屏幕上方空间不足时菜单翻转到按钮下方；
- [ ] 点击外部、滚动页面、执行查询或切换页面后菜单消失；
- [ ] Oxford 接收正确英文；
- [ ] ChatGPT 运行名为 `AI查询` 的快捷指令；
- [ ] 快捷指令输入需要用户在交付后单独确认；
- [ ] 高关联词 `data` 的超长 URL 行为单独记录。

## 弹窗、搜索与键盘

- [ ] 确认、表单、操作和搜索窗口均保留明显边缘留白；
- [ ] 打开任何含输入框的窗口时不自动弹出键盘；
- [ ] 用户点击输入框后才进入编辑；
- [ ] 搜索键盘出现时窗口不冲入状态栏；
- [ ] 搜索结果在窗口内滚动，背景页面不移动；
- [ ] 关闭键盘和搜索窗口时无瞬时上下闪烁；
- [ ] 弹窗开合不改变背景词表位置。

## Seed 与数据安全

- [ ] 选择还原到 Seed 后先出现“下载备份／不下载”小窗口；
- [ ] 两个备份选项都会继续进入 Seed 操作确认；
- [ ] 备份选择窗口不能通过背景或返回键跳过；
- [ ] 后续确认窗口取消时不修改数据；
- [ ] 确认后正确恢复 Seed；
- [ ] 恢复完整备份、VIX 完整替换、删除词域／词表／内容采用相同两阶段流程；
- [ ] 增量合并不错误触发高危备份选择；
- [ ] 完整备份恢复 PIN、标注、日期、位置和设置。

## 缩放与辅助功能

- [ ] 双击日常区域不触发意外缩放；
- [ ] 输入框聚焦不触发页面放大；
- [ ] 正常滑动和点按中几乎不会误触缩放；
- [ ] VoiceOver 正确读出英文、释义、日期、按钮和关联状态；
- [ ] Switch Control／全键盘访问显示可见焦点；
- [ ] 减少动态效果后覆盖层和菜单仍可正常使用。

## 性能

- [ ] 打开全局词汇总表无长时间白屏；
- [ ] 展开大型字母组无明显冻结；
- [ ] 日期模式 5,322 项未标注区可连续滚动；
- [ ] 惰性块接近视口时无长期空白或明显高度跳变；
- [ ] 快速点击 PIN、关联、日期刷新仅局部更新；
- [ ] 查询菜单开合无明显迟滞；
- [ ] 搜索输入和范围切换流畅；
- [ ] 长距离滚动后内存与触控响应保持稳定。
