# 3.4.0 iPhone 主屏幕 PWA 人工验收清单

> 目标：在真实 iPhone Safari 添加到主屏幕后验证 3.4.0。逐项记录机型、iOS 版本、测试数据状态和结果。桌面 Chromium 只能作为烟雾测试，不能替代本清单。

## 安装、状态栏与生命周期

- [ ] 冷启动显示版本 3.4.0，旧 Service Worker 不再提供 3.3.1 资源；
- [ ] 页面背景与状态栏自然衔接，不侵入时间、灵动岛、信号和 Home Indicator；
- [ ] 从后台、锁屏、Oxford 和 ChatGPT 返回后，页面宽度、缩放和当前位置保持；
- [ ] Service Worker 更新提示、立即更新与完全重启正常；
- [ ] 应用内返回首页恢复首页滚动位置，冷启动首页从顶部开始。

## 首页与视觉基线

- [ ] 固定顶栏标题严格视觉居中，不受左右按钮宽度影响；
- [ ] 首页左侧装饰竖线已完全移除；
- [ ] 全局区域使用平整纯色表面，不出现光晕或方向性渐变；
- [ ] 全局和域内系统表卡片无廉价阴影、浮雕或玻璃渐变；
- [ ] 首页卡片使用“进入词表”图标，不与关系跳转三态图标混淆；
- [ ] 顶部置顶图标在按钮框内水平、垂直及视觉中心一致；
- [ ] 管理窗口关闭按钮保持足够触控区，但视觉外框不过重。

## 系统总表投影模型

- [ ] 域内总表中，同一具体 Entry 因多个普通表 Membership 只显示一次；
- [ ] 全局词汇总表中，跨域同形词分别显示为多行；
- [ ] 全局短语总表中，跨域同形短语分别显示为多行；
- [ ] 冲突行右上方显示低强调度来源域副字，非冲突行不显示；
- [ ] 全局标题和首页卡片总数按唯一规范文本组计数，不按实际渲染行数重复统计；
- [ ] 调整独立域顺序，只改变同形组内各域 Entry 的显示先后；
- [ ] 调整独立域顺序不迁移、不复制、不删除 PIN、AI 标注或学习日期；
- [ ] 每个跨域同形 Entry 的释义、日期、PIN、标注、关系和编辑均独立。

## 排序与序号

- [ ] 连续编号在字母和日期模式下都继承字典序词形组序号；
- [ ] 连续编号下，跨域同形 Entry 始终共享编号；
- [ ] 字母模式“小标题内编号”在每个字母内重新从 1 开始；
- [ ] 同一字母内的跨域同形 Entry 共享小标题内编号；
- [ ] 日期模式“小标题内编号”在每个具体日期和“未标注”内分别从 1 开始；
- [ ] 同形 Entry 位于不同日期组时允许显示不同局部编号；
- [ ] 同形 Entry 位于同一日期组时共享该组局部编号；
- [ ] 设置文案显示“小标题内编号”，不再显示“字母内编号”；
- [ ] 三位和四位序号不覆盖英文，序号轨道与正文轨道稳定分离；
- [ ] 无序号模式释放左侧空间，不保留完整四位序号空槽。

## 字母导航与动态小标题

- [ ] 当前阅读字母变化时，顶部对应按钮更新选中态；
- [ ] 当前字母按钮仍在轨道可视区时，轨道不自行移动；
- [ ] 当前字母按钮完全离开可视区时，仅将其带回可视范围，不强制居中；
- [ ] 手动横滑字母轨道时暂停自动跟随，手势结束后正确同步；
- [ ] 展开的真实字母小标题到达动态顶栏下方后吸附；
- [ ] 下一字母小标题自然推出并接替当前吸附标题；
- [ ] 点击吸附中的字母小标题后折叠该组；
- [ ] 折叠完成后，该小标题保持在折叠前的屏幕坐标，不明显跳动；
- [ ] A–Z 与 # 的行为一致；日期标题不错误获得字母折叠行为。

## Large Title、位置恢复与覆盖层

- [ ] Large Title 完整展开时不被固定顶栏切断；
- [ ] Large Title 收缩过程自然，不停在只露半行的状态；
- [ ] 恢复上次位置后，Large Title、当前字母和 sticky 状态立即正确；
- [ ] 全局词汇／短语总表的字母、日期模式均可恢复上次位置；
- [ ] 域内总表和普通表的词汇／短语分区位置互不污染；
- [ ] PIN 条、标注审阅条、更新提示和字母小标题不相互遮挡；
- [ ] 跳转目标始终落在所有顶部覆盖层下方的可读区域；
- [ ] 返回顶部按钮始终存在，但不遮挡一级表项操作。

## 零数量分区状态

- [ ] 0 条词汇或短语时保留现行标题、模式控制、禁用字母与空状态；
- [ ] 手动新增第一条内容后，空状态消失、对应字母启用、内容出现；
- [ ] VIX／普通导入新增第一条内容时行为一致；
- [ ] 删除最后一条内容后，空状态恢复、字母禁用；
- [ ] 上述 0↔1 转换在字母与日期模式均正确，不留下旧控件状态。

## 一级表项、横滑与短语溢出

- [ ] 日期不存在时不保留完整日期空槽；
- [ ] 当前 Seed 中绝大多数普通词无需横滑即可完整显示；
- [ ] 真正超长词使用横滑，不省略、不换行、不挤压固定操作区；
- [ ] 横滑边缘提示只在真实溢出时出现，并随 scrollLeft 正确更新；
- [ ] 节点绑定新 Entry、惰性块重新物化、切换词表／模式／序号／释义后 scrollLeft 归零；
- [ ] 同一可见周期内用户主动横滑可以保持；
- [ ] 轻点复制，实际横向手势后不误复制，纵向滚动不误判；
- [ ] 常规短语完整显示；两行短语真实溢出时自动升级为极限布局；
- [ ] 两行 Clamp 不静默隐藏完整短语或释义；
- [ ] 极限短语只渲染实际存在的日期和操作，不留无效空槽；
- [ ] 跨域冲突来源副字不覆盖英文、释义、日期或操作按钮。

## 关系与三态跳转

- [ ] 只有一个域内目标时显示域内图标，点击直接跳转；
- [ ] 只有一个域外目标时显示域外图标，点击直接跳转；
- [ ] 有两个及以上有效目标时显示多目标图标；
- [ ] 多目标图标打开锚定式紧凑扁平列表，不自动选择优先目标；
- [ ] 列表按独立域顺序、词表顺序和分区顺序稳定排列；
- [ ] 目标较多时仅窗口内部滚动，不扩张为全屏 Sheet；
- [ ] 弹窗靠近屏幕边缘时自动避让并保留安全边距；
- [ ] 点击外部、选择目标、Escape／关闭行为正确，焦点返回触发按钮；
- [ ] 菜单只列出真实可见且可定位的目标，不出现“位置已失效”；
- [ ] 关系来源域以当前具体 Entry 的 domainId 判断；
- [ ] 首页固定卡片不误用三态关系图标；
- [ ] 展开关系不导致当前一级表项跳离视口。

## PIN、AI 标注与学习日期

- [ ] PIN 绑定具体 Entry，在普通表、域内总表和全局总表投影中状态一致；
- [ ] 在任一投影视图取消 PIN 后，其他投影同步取消；
- [ ] 跨域同形 Entry 可以分别设置或取消 PIN，互不影响；
- [ ] 跨域同形 Entry 的 AI 标注分别显示和处理；
- [ ] 全局冲突行的审阅条明确显示来源域；
- [ ] 跨域同形 Entry 的学习日期独立设置、刷新和清除；
- [ ] 重命名发生日期冲突时保留日历日期较晚者；日期相同保留刷新时间较晚者；
- [ ] 被标注表项点击进入处理而不是复制，独立操作按钮仍正常。

## AI 核查事务

- [ ] 一次完整 AI 核查无论多少批次，只在 Undo 中产生一条记录；
- [ ] 撤销该记录只恢复任务开始前的 Annotation，不撤销正文、PIN 或日期；
- [ ] 核查期间编辑 Entry 后，旧 AI 结果不写回且不删除旧标注；
- [ ] 点击取消后当前 Fetch 与重试等待立即中止；
- [ ] 恢复、Seed 重置、完整导入和删除词域会中止正在运行的 AI 任务；
- [ ] 大型核查不会挤掉大量人工 Undo 历史；
- [ ] AI 批次写入期间页面不反复整库重绘或明显跳动。

## 搜索与查询

- [ ] 当前词表搜索先限定范围再排序，不因全局前 180 条截断而漏结果；
- [ ] 用 `a` 在 A1、B2、AWL 和计算机词表中测试，结果数量与范围数据一致；
- [ ] 全局总表可用具体域 Entry 的繁体释义搜索；
- [ ] 跨域同形词两个实例都匹配时显示两条，并显示来源域；
- [ ] AI 联想搜索也遵守当前范围；
- [ ] 搜索窗口打开时不自动弹键盘，点击输入框后才聚焦；
- [ ] 搜索结果窗口滚动时背景页面不移动；
- [ ] Oxford 接收正确英文；ChatGPT 调用名为 `AI查询` 的快捷指令；
- [ ] 外部应用返回后当前位置和横滑状态符合规则。

## 导入、VIX 与高危操作

- [ ] 导入预检记录基准 Revision；确认前数据变化时重新预检，不提交过期 Plan；
- [ ] 歧义裸 Entry 键不自动猜测，相关脏 Membership 被跳过；
- [ ] 预检报告列出原始键、候选对象和被跳过关系；
- [ ] 其他合法内容继续导入；
- [ ] 指针排序手势被系统取消时不提交半完成顺序；
- [ ] 高危操作先显示“下载备份／不下载”小窗口；
- [ ] 两个备份选项都会继续进入实际操作确认；
- [ ] 最终确认取消时不修改数据；
- [ ] Schema 4 完整备份可迁移到 Schema 5；
- [ ] 旧全局学习日期只迁移到旧规则代表 Entry，不复制给全部跨域同形 Entry；
- [ ] 迁移报告明确列出歧义迁移项。

## 弹窗、键盘与辅助功能

- [ ] 搜索、管理、表单、确认和多目标窗口均保留屏幕边缘留白；
- [ ] 背景滚动锁定可靠，关闭窗口后原位置不变；
- [ ] 输入框聚焦不触发页面异常放大；
- [ ] VoiceOver 正确读出来源域、序号、日期、PIN、标注和三态跳转；
- [ ] 键盘用户可打开、导航和关闭多目标菜单；
- [ ] 减少动态效果后 sticky、弹窗和折叠位置补偿仍正常。

## 性能

- [ ] 打开全局词汇总表和全局短语总表无长时间白屏；
- [ ] 跨域同形分组不在滚动事件中重复构建；
- [ ] 展开大型字母组无明显冻结；
- [ ] 日期模式大型未标注区可持续滚动；
- [ ] 惰性块物化无长期空白或明显高度跳变；
- [ ] 当前字母跟随只在小标题变化时更新，不产生持续抖动；
- [ ] 只测量可见短语，不出现大规模同步布局测量；
- [ ] 搜索、PIN、关系、日期刷新和查询菜单保持流畅；
- [ ] 长距离滚动后内存与触控响应稳定。
