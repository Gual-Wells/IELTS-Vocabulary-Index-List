# iPhone Safari 最终验收清单

## 安装与离线

- Safari 打开 GitHub Pages 地址，首页正常显示。
- 添加到主屏幕后以 standalone 模式启动。
- 飞行模式下重新打开，已有词表仍可浏览、编辑和搜索英语词汇。
- 离线时 AI 操作给出网络错误，不影响本地数据。

## 核心复制流程

- 点按词汇后显示“已复制”。
- 运行现有快捷指令，牛津英汉辞书打开后可手动粘贴。
- 含撇号、连字符、逗号和短语的词汇复制内容完整。

## 全局重复

- 在较晚词表新增已存在词汇，只合并词性，不产生第二条。
- 在较早词表导入较晚词表已有词汇，词条自动移动到较早词表。
- 从较早词表移除多来源词汇，词条回落到下一个来源词表。
- 调整词表顺序后，重复词归属随优先级变化。

## 导入与撤销

- 对异常 CSV 执行预览，不会清空当前词表。
- 分别验证“合并”和“替换”。
- 导入后撤销，数据恢复；重做后再次应用。
- 完整 JSON 备份可在清空测试数据后恢复。

## 搜索与书签

- 英语前缀、包含、子序列和轻微拼写错误均能找到词汇。
- 首页全局结果显示词表标签。
- 中文 AI 联想能返回本地匹配结果。
- 一个词表固定多个书签，前后按钮循环跳转。
- 退出词表再进入，恢复上次浏览词条。

## AI

- API Key 读取模型列表成功。
- AI 新增只显示词汇和词性。
- AI 核查只产生标注，不自动修改词汇。
- 取消单条标注和清空当前词表标注均正常。
- 中途取消批量核查，已完成批次的标注保留。
